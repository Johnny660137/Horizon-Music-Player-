# Horizon Music Player (HMP)

A native Android music player built with Kotlin, Jetpack Compose and AndroidX Media3.

## Planned features
- Scan local audio using Android MediaStore
- Native music library and search
- Background playback through MediaSessionService
- Notification and lock-screen controls
- Shuffle queue and smooth crossfade transitions
- Nano-inspired dark interface with subtle horizon gradients

## Build
Open this repository in Android Studio, or use the GitHub Actions workflow to build a debug APK. The APK is a development build and should be tested on a real device before release.
